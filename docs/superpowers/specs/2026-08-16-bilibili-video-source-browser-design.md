# B站视频来源浏览设计

## 目标

在不触发导入的前提下，让用户从“我的收藏夹”或指定 UP 主的投稿中浏览视频、查看基本信息并完成勾选，为后续批量导入提供输入。

## 今日范围

- 新增“从 B站选择”页面入口。
- 收藏夹模式使用三项 Cookie 获取当前账号收藏夹和分页视频。
- UP 主模式接受 UID 或空间链接，可选是否携带三项 Cookie。
- 视频列表展示封面、标题、UP、时长、发布时间和不可用状态。
- 支持当前页全选、逐项选择和跨页保留已选 BV。
- 不创建导入任务、不持久化选择、不保存 Cookie。

## 接口与数据流

前端通过三个 POST 查询接口把凭证放在 JSON body 中，避免进入 URL、代理访问日志和浏览器历史。后端在应用登录校验后调用 B站接口：收藏夹先从 nav 获取当前 mid，再查目录；UP 投稿使用 nav 返回的 WBI key 计算签名。第三方错误统一转换为稳定业务错误，不把 Cookie 或完整上游响应写入日志。

## 边界

- 收藏夹查询必须携带完整三项凭证。
- UP 匿名模式不发送三项凭证；若被 B站风控，返回明确的“请求被 B站限制”，用户可改用登录模式。
- 收藏夹失效视频保留展示但禁用选择。
- 页面只保存内存状态，刷新即清空凭证与选择。

## 验证

- 后端覆盖 WBI 签名、UID 解析、上游响应映射、错误转换和 Controller 契约。
- 前端运行生产构建，并使用开发 Mock 验证收藏夹、UP、分页、全选和禁用状态。
